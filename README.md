## 📌 Latar Belakang & Key Insights
Repositori ini berisi proyek dashboard interaktif untuk menganalisis katalog film dan serial televisi di platform Netflix menggunakan Python (Streamlit & Plotly). 

### Temuan Penting (Key Insights):
1. **Pertumbuhan Pesat:** Penambahan konten baru mengalami peningkatan tajam sejak tahun 2015.
2. **Dominasi Format:** Konten berjenis *Movie* mendominasi porsi terbesar dari keseluruhan katalog.
3. **Rating Usia:** Segmentasi penonton mayoritas berada di kategori dewasa (*TV-MA*).

---

## 🛠️ Panduan Menjalankan Kode Secara Lokal
1. Pastikan Python telah terinstal di komputer Anda.
2. Unduh atau *clone* repositori ini.
3. Instal pustaka yang dibutuhkan melalui terminal:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan aplikasi Streamlit dengan perintah:
   ```bash
   streamlit run app.py
   ```
